# Standalone Adoption Note v0.1.2

The frozen Lore Fragment / Exegate Harvest semantic documents were originally ratified under `LV-FORGE-*` identifiers. Those identifiers are retained verbatim for provenance and backward compatibility.

As of the standalone architecture freeze, every normative sentence assigning deterministic materialization to "LV-Forge" is implemented by **Liber Harvest's deterministic core**. This is an ownership transfer only; it changes no LF-01 through LF-16 semantics, field names, controlled vocabularies, schema versions, or identity rules.
